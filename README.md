# Musewell 🧠📝

Musewell is a minimalist note-taking web app that lets users create, edit, update, and delete their personal notes with ease. Built with a simple CRUD structure, it focuses on clarity, privacy, and functionality.

---

## ✨ Features

- 🖊️ Create, read, update, and delete notes
- 🔐 User-based access: only logged-in users can see their own notes
- 💾 MySQL database integration
- 💻 Clean and responsive UI with HTML & CSS

---

## 🛠 Technologies Used

- Python (Flask)
- MySQL
- HTML & CSS
- Jinja templating

---

## 🔒 Security

- User sessions are protected with Flask sessions
- Notes are retrieved from the database based on the logged-in user ID only
